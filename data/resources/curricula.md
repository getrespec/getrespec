Used for topic order and "further reading" links when building a curriculum. **Content is linked, never copied.** Lessons and exercises are generated by Respec. Check a resource's license before reusing any of its content.

Columns: **Roles** = which roles it fits (`roles.md` ids), **Cost** = free/paid.

## Suggested order (for a working developer)

A practical order suggested by one roundup ([daily.dev](https://daily.dev/agentic-ai-hub/learning-paths-courses-books/)): orient with roadmap.sh/ai-engineer → Karpathy's Zero-to-Hero for model internals → a few DeepLearning.AI short courses on RAG and agents → *AI Engineering* (Huyen) → ship something real. In Respec, the Karpathy step is optional for every role except ML Engineer.
