What is this?

The context window is how many tokens one request can hold: your instructions, the chat history, the customer's new message, and the room you reserve for the answer. The API is stateless, so the bookstore's support chat sends the whole conversation again on every request.

How to read it

The bar is one request's window (8,000 tokens here). The slider is how many questions the customer has asked so far. Dark blue is the history (earlier questions and answers), light blue is your system prompt with the store's policies, and yellow is max_tokens, the room you reserve for the answer.


Takeaway: the history grows with every question and eats the window, and you pay for all of it on every request. Long support chats need trimming or a short summary of old turns, or the request is eventually rejected.
